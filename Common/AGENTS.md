# Common - Shared Utilities and Data Formats

## Overview

Foundation layer (`namespace common`) with no dependencies outside the codebase. Provides utilities, data formats, threading, logging, and math helpers consumed by DataPacker, Engine, and Projects. Broadly-used singletons and small headers sit at the `Common/` root; focused groups live in subdirectories: `Log/` (logging, formatters, diagnostic/difference logs), `Threading/` (multithreading, persistent worker, thread-local), `Math/` (math helpers, convex-hull placement, random). New headers are added only to `Common.h` (the aggregation header included by `Pch.h`).

## Key Systems

- **DataFile.h** - `.pack` binary format: 16-byte aligned chunks, type-tagged `ChunkHeader` (per-type union of scene/island/model/shader/texture/audio headers). `DataHeader::kiVersion` incorporates `sizeof(ChunkHeader)`, so layout edits that change that size auto-bump the version (DataPacker re-exports everything on a manifest version mismatch), and export jobs fold serialized payload-struct sizes into their chunk-cache versions; edits invisible to both `sizeof`s (same-size reorders, non-largest union members) are caught instead by per-struct `sizeof`/`BT_OFFSETOF` `static_assert`s whose messages name the version to bump. The per-type payload header structs (`ShaderHeader`, `SceneHeader`, `ModelHeader`) carry `static constexpr` offset helpers as the single source for payload layout math between DataPacker writers and engine readers; `kiAnimationSectionAlignment` (4-byte alignment, distinct from the 16-byte `kiAlignmentBytes`) serves the same role for the animation section boundary. Defines the shared elevation constants `kfSeaBottomMeters` (engine-wide sea-floor; unifies the elevation render-target clear with the CPU `GlobalElevation()` open-ocean fallback — DataPacker asserts each island's per-bake value matches) and `kfUnderwaterMaskThresholdMeters` (depth below which island textures are zeroed at bake and above which a pixel joins the valid-area convex hull).
- **Workbuffer** - Stack allocator via `gpThreadLocal->mWorkbuffer`. `Push()` returns a `[[nodiscard]] ScopedWorkbufferArena` (RAII scope, dtor pops); `PushBuffer<T>(size)` returns a `[[nodiscard]] ScopedWorkbufferAllocation<T>` (typed pointer + RAII, move-only — ownership transfers and the source goes inert, so it can be returned from helpers). `Pop()` is private — only the RAII handles call it. The arena type forwards `Append`/`AppendFloat`/`PushBack<T>`/`View`/`Span<T>`/`ShrinkLastPushBuffer` and is used for both flat scratch frames and loop- or lambda-driven content; `Append` has both a `string_view` and a `wstring_view` overload (the latter UTF-8-converts wide input into the buffer with no heap allocation); these accessors are valid only within an open frame (read/append at depth 0 asserts, since the buffer is frame-relative). Every open frame starts 16-byte aligned (`RawPush`/`RawPushBuffer` round the base up to 16), so `PushBuffer<T>` reservations are SIMD-safe (`XMVECTOR`/`XMMATRIX` `movaps`) by construction. `std::formatter` integrates with `LOG()` via per-argument wrappers (`Wb`, `WbV2`/`WbV3`/`WbV4`) and a passthrough specialization on the arena itself. **Invariant**: growth path calls `DEBUG_BREAK()` — buffers must be sized correctly up front. Non-copyable/non-movable (holds a reference to its backing vector).
- **Crc.h** - The codebase-wide non-standard 64-bit `Crc()` hash family (string / pointer+count / trivially-copyable / `XMVECTOR` overloads), `FixedString`/`ConstexprCrcArray`/`IntToString` (compile-time), and the `NotStringLike` concept.
- **Serialization.h** - Engine-wide binary `Read`/`Write` stream overloads (see Binary Serialization) and `VectorByteSize`.
- **StringUtils.h / FileUtils.h / AlignedMemory.h / TextureFormat.h** - Offline string helpers (`ToString`, `ToLower`, `Split`, `PathToCppVariable`, zero-alloc `ToHex`), file helpers (`ReadEntireFile`, `ContentsEqual`, `GetFileOrStringContent`), 64-byte-aligned SIMD storage (`AlignedUniquePtr`/`MakeAligned`/`AlignedDeleter`), and Vulkan texture size utilities: `SizeInBytes` (single-mip byte size for a format/extent) and `ComputeImageByteSize` (full mip-chain byte size, clamping mip dimensions at 1 — single source of truth for upload sizing and cache validation).
- **AllocationTracking.h** - Global-namespace (not `common::`) thread-local suppression counter + two RAII guards: `ScopedSuppressAllocationTracking` (increments the counter, disabling tracking for its scope) and `ScopedResumeAllocationTracking` (decrements the counter inside an active suppress scope, re-arming the tracker for a callee that is designed to run with the tracker armed — e.g. a workbuffer-based function called from a caller that holds a blanket suppress guard). The Engine allocator reads the counter for main-loop tracking; tools builds have no allocator override, so common-layer code (e.g. `DiagnosticLog`) can suppress unconditionally. Usage rules: root `../AGENTS.md` "Allocation tracking".
- **Math/MathUtils.h** - XMVECTOR helpers (color pack/unpack, direction/quaternion/rotation builders, jitter, `Distance`, `ComputeLeadPosition` projectile lead-solver), integer/float rounding (`RoundUp`/`RoundDown`), `MinAbs`/`Ceil`, `ValidateVector`, and the deterministic transcendental replacements — Padé exponentials and `DeterministicSinCos` (see Determinism).
- **Math/ConvexHull.h** - Deterministic 2D convex-hull placement system (`ConvexHull2D` + `BuildWorldHull` + AABB broadphase + SAT `ConvexHullsOverlap` + the `IsPolygonCcw` shoelace CCW predicate, single-sourced for the nav winding test and the DataPacker hull verifier) used by island-chain packing (rectangles may overlap underwater, hulls may not).
- **Flags\<EnumType\>** - Type-safe bitfield wrapper; serializable and CRC-hashable. Underlying type must be unsigned.
- **Threading/Multithreading + Threading/PersistentWorker** - `gpMultithreading->Dispatch` worker pool. The primary ctor sets `gpMultithreading`; a second ctor (named `Threads` id + workbuffer size) builds a separate non-global pool and leaves the singleton untouched. Workers run at `THREAD_PRIORITY_TIME_CRITICAL` and own a private `ThreadLocal`. `Dispatch` is non-reentrant per pool and drains every worker before rethrowing the first exception (logging later failures), so a throw never leaves a worker running against the unwound caller stack. `PersistentWorker` (long-lived single worker) enforces a strict contract via `ASSERT`: one `Wake` per `Wait`, `Wait` before the next `Wake`, `Wait` before destruction, all from one calling thread; non-copyable/non-movable (worker lambda captures `this`).
- **Threading/ThreadLocal** - Per-thread storage (log buffer, Workbuffer, tick/indent context, a frame-tick-in-progress flag set by a scoped RAII guard so other layers can assert against running from frame-tick code, optional named thread id from the `Threads` enum). Ctor calls into `Determinism.h` to set MXCSR and install exception handlers (handler install has a per-ctor opt-out; see Determinism / Exception Handling below). Exactly one per thread (ctor `ASSERT`s `gpThreadLocal == nullptr` and owns it for its lifetime); non-copyable/non-movable (buffers alias its own backing vectors).
- **Math/Random (RandomEngine)** - Xorshift64 seeded via splitmix64, with equality + CRC for replay/desync verification. All gameplay randomness flows through this — never `std::random`. Draw contracts call sites rely on: float draws are half-open `[0, max)`, the bounded integer draw is inclusive `[0, max]`, and every draw advances the engine exactly one step (extra or skipped draws shift the stream and desync replays). Default-constructed engines all share one state — explicitly seed each independent stream; `TimeSeed()` is non-deterministic by contract (never seed sim state from it without broadcasting the seed).
- **Smoothed\<T, COUNT\>** - Rolling buffer with slow-drift near target, snap on large gap.
- **InTheLastSecond / Timer** - Time-windowed event counter and high-resolution steady-clock timer.

## Architecture Notes

### Determinism (centralized in `Determinism.h`)
- **`Determinism.h`** holds deterministic exact (non-epsilon) IEEE `operator==` for `XMFLOAT2/3/4` / `XMVECTOR`: `-0.0f` equals `+0.0f`, and NaNs never compare equal. Byte-identity consumers use `memcmp` (as in `LogDifference`). It also declares `ConfigureThreadFloatingPoint()` (MXCSR) and `SetupExceptionHandling()`. `ExternalHeaders.h` includes it right after its DirectXMath includes (so the operators are globally visible) and still owns the SSE4-only build knob, the PI subdivisions, `kfEpsilon`, and `XmIsNan`/`XmIsInf`.
- **DirectXMath**: SSE4-only; AVX/AVX2 banned as non-deterministic across CPUs. Enforced by `#error` guard in `ExternalHeaders.h`.
- **MXCSR**: Every thread's `ThreadLocal` ctor calls `ConfigureThreadFloatingPoint()` to set flush-denormals + round-to-nearest for cross-thread FP consistency.
- **CRC**: `Crc()` (in `Crc.h`) is constexpr; `XMVECTOR` hashing round-trips via `XMFLOAT4` for consistent layout.
- **ValidateVector\<IS_POSITION\>**: `Math/MathUtils.h` helper asserting all 4 lanes finite plus the W invariant (positions W=1.0, directions/velocities W=0.0). Called at collection Spawn/Transfer boundaries to catch W-lane corruption before it poisons downstream `XMVectorMultiplyAdd` / `XMVector3Normalize` consumers. See root `../AGENTS.md` "XMVECTOR W invariant".
- **Math helpers**: `Math/MathUtils.h` keeps libm transcendentals out of sim/CRC-fed code. `ExponentialDecay` is a total Padé (1,1) decay factor in `[0, 1]`: non-positive or NaN scaled time returns `1.0f`, positive infinity returns `0.0f`, and finite positive scaled time uses the clamped rational approximation. `ExponentialInterpolant` is the corresponding unclamped interpolation factor; it stays in `[0, 1]` only for scaled time in `[0, 2]`, so callers outside that domain must clamp the result. Prefer these helpers over `std::exp`-based lerps. `DeterministicSinCos`: wraps DirectXMath's header-inline `XMScalarSinCos` minimax polynomial (basic IEEE ops only) — the sanctioned sin/cos for anything feeding CRC'd or client/server-shared state, since libm `std::sin`/`std::cos` rounding differs across toolchains; render-only paths may still use libm trig.

### Binary Serialization
- `Read`/`Write` helpers in `Serialization.h` are the engine-wide binary I/O pattern for trivially-copyable types and `std::vector<T>`. `XMVECTOR` overloads round-trip via `XMFLOAT4`. Do not `reinterpret_cast` manually.
- **Trust-boundary count validation** (`Serialization.h`): a deserialized element count/size/capacity from a save file, replay stream, network payload, or `.pack` chunk is opaque input — validate it before it drives a `resize`/`reserve`/loop/allocation. `ValidateDeserializedCount(count, elementBytes, stream, name)` bounds a sequential-read count against the stream's remaining length (`StreamBytesRemaining`, seekable streams only); `ValidateDeserializedCountCapacity(count, capacity, elementBytes, stream, name)` adds the SOA `count <= capacity <= kiMaxDeserializedCapacity` invariant plus a `kiMaxDeserializedBytes` (256 MiB) ceiling on `capacity * elementBytes`, so a large per-element stride can't reserve multi-GB before the count is read. Both throw `CorruptStreamException` on failure; the deserialization boundary (network receive, save/replay load, `.pack` asset load) catches `const std::exception&` and degrades gracefully (skip packet / abort load / soft-fail chunk) instead of overrunning a buffer or allocating unboundedly. `.pack` parsers with fixed structural maxima bound against the `DataFile.h` `kiMax*` constants instead.

### Logging (`Log/` subdirectory)
- **Public API**: `LOG(category, level, format, ...)` (`Log/Log.h`) — two-stage filtered. Compile floor: per-category `keLogLevel*` thresholds each project defines in `Pch.h` (assembled into `keLogLevels[]` in `Log/Log.h`), so below-floor calls are eliminated by `if constexpr`. Runtime gate: per-category `gLogRuntimeLevels` thresholds (default `kInfo`; `kVerbose` under `BT_DATA_PACKER`) checked before formatting, so a compiled-in call still no-ops until its category is raised at runtime (the agent `set_log_level` command adjusts these, clamped up to the compile floor).
- **Tick tagging**: `LogTickScope` (RAII, nestable) prefixes all logs within a tick; its sibling `LogIndentScope` (both in `Threading/ThreadLocal.h`) sets an absolute indent for cross-thread propagation into workers — distinct from the delta-based `ScopedLogIndent` (`Log/Log.h`) used for ordinary nesting.
- **Buffers**: Lockless per-category ring buffers; each thread formats into its own buffer (the `ThreadLocal` log buffer, or a per-thread `thread_local` fallback for threads without a `ThreadLocal`), so only the emission step (`OutputDebugString`/`printf`) holds a mutex. A counter suppresses the vectored exception handler from re-logging the engine's own debug-string calls. The non-wrapping global ring is the crash-dump snapshot; a separate cross-category wrapping ring (`gLogAgentBuffer`) backs the agent `get_logs` query. An optional file sink (`EnableLogFile`) mirrors each emitted line to disk (write + flush, allocation-suppressed).
- **Formatters**: `Log/LogFormatters.h` provides `std::formatter` specializations so `LOG`/`std::format` handle engine types directly (`XMVECTOR`/`XMFLOAT2/3/4[A]`, `Flags`, `RandomEngine`, paths/wide strings, chrono durations, narrow int8/uint8, Vulkan enums — which print enum names via the SDK's generated `string_VkX` helpers — and the `Wb`/`WbV2`/`WbV3`/`WbV4` workbuffer float wrappers). All are allocation-free (paths/wide strings route through the workbuffer; Vulkan enums return static literals; the rest use stack buffers) and support width/precision/fill internally, but allocation-tracked Game/Engine `LOG` call sites must not request those specs; `/repo-code-review` owns the exact accepted call-site forms. Add new specializations for common-visible types here; formatters for engine-layer types live with the type's hub instead (since Common cannot see them) — `Engine.h` hosts `uuid_t`/`id_t<T>`/`alignment_t`/`Alignments`, and `Frame/Collections` hosts `global_id_t`.
- **DiagnosticLog / LogDifference** (`Log/DiagnosticLog.h`, `Log/LogDifference.h`): `FILE_LOG_INIT(i, file)` / `FILE_LOG(i, ...)` write per-file diagnostic logs (up to 4 concurrent, flushed each line, allocation-tracking suppressed). `LogDifference<NAME>` drives field-by-field desync diagnosis using `FixedString` NTTP labels and a scoped section-context tag.
- **`kTemp`** category is reserved for transient agent diagnostics.

### Exception Handling
- `ThreadLocal` ctor calls `SetupExceptionHandling()` (`Determinism.h`). The per-thread CRT handler slots (SEH translator, invalid-parameter handler) install on every ctor; the process-global handlers (vectored exception handler, terminate handler, error-mode / CRT-report setup) install exactly once via `std::call_once`, so concurrent ctors are race-free and the vectored handler is registered only once. Combined with `/EHa`, this promotes structured faults into C++ exceptions and logs a `LogStackWalker` (`StackWalker.h`) call stack before `DEBUG_BREAK()`; stack overflow logs a fixed error and skips the stack walk before breaking. A `ScopedExpectedThrows` guard (thread-local `giExpectedThrowDepth`) marks designed throw regions so the handler skips the stack-walk/break diagnostics for C++ throws (other fault codes still diagnosed).
- **Stack walkers** (`StackWalker.h`): `LogStackWalker` (LOG sink) and `OfstreamStackWalker` (crash-report file sink) are thin sinks over `FilteredStackWalker`, whose `ShowCallstack()` serializes every walk on the process-wide `gDbgHelpMutex` (`Determinism.h`; dbghelp.dll is single-threaded per process) — contended walks are skipped rather than hanging a crashing thread. Frame formatting is allocation-free and emits named frames lacking line info in offset form instead of dropping them.
- **Validation macros**: `ASSERT` / `CHECK_HRESULT` / `VERIFY_SUCCESS` all `DEBUG_BREAK()` + throw on failure with `std::source_location`. `DEBUG_BREAK()` only fires with a debugger attached. Standard `assert` is `#define`d to a compile error — use `ASSERT`. Each also carries a no-codegen `_Analysis_assume_` post-condition so Release `/analyze` (PREfast) models the asserted predicate as holding on fall-through (kills C6011-class warnings on the `ASSERT(p); p->...` pattern); expands to nothing in normal builds. Engine's `CHECK_VK` (`Graphics/GraphicsUtils.h`) carries the same `_Analysis_assume_` but routes failures through a recoverable/fatal classifier rather than always breaking+throwing (see [Graphics/AGENTS.md](../Engine/Source/Graphics/AGENTS.md)).

### Headers, Platform
- **ExternalHeaders.h** - Central include for PCH-backed external/standard-library headers, gated by `BT_CLIENT`/`BT_ENGINE`/`BT_SERVER` and a `BT_DATA_PACKER` block for offline tooling. **Inclusion rule**: `#include` additions for standard-library and third-party *consumption* headers in Common, Engine, Projects, and DataPacker go here (gated by `BT_CLIENT`/`BT_ENGINE`/`BT_SERVER`/`BT_DATA_PACKER` as appropriate), never in individual source files. The PCH-less AgentTools instead centralize shared standard-library and third-party consumption headers in `Tools/ToolCommon/ToolCliCommon.h`. Third-party library implementation units under `ThirdParty/Prebuilts/Source/` keep their own upstream implementation headers and sources local by necessity. Also sets the determinism build knobs (SSE4-only DirectXMath, AVX `#error` guard), includes `Determinism.h` (which carries the deterministic `XMFLOAT2/3/4` / `XMVECTOR` `operator==`; see Determinism above), and defines `BT_OFFSETOF` (constexpr-safe `offsetof`, used by the DataFile.h layout locks).
- **WindowsUtils.h** - Win32 wrappers (last-error/HRESULT string formatting, file-time formatting, physical/logical core counts, child-process launch/capture) used mostly by tools and startup.
- **ScopedLambda** - RAII deferred callable for cleanup that doesn't fit other scope guards.
