# Lighting Shaders - Dynamic Light Rendering and Spreading

## Overview

Fragment and vertex shaders for rendering dynamic lights, plus compute shaders for the spreading pipeline. Two rendering paths: deposit shaders write lights into MRT EWNS directional-lighting textures, which the spreading pipeline processes into the scene-lighting textures sampled by Terrain/Water/Model shaders; visible lights render directly to the main framebuffer as additive billboards.

(The hub `../AGENTS.md` owns the shared deposit conventions — scalar block layout, bindless textures, multi-set descriptors, four-channel EWNS, and the *light-source* directional-deposit family (world-space cos^2 weighting, epsilon omnidirectional fallback) that this directory's depositors use. Not repeated here.)

## Shaders

- **AreaLight.frag / PointLight.frag** - MRT deposit of oriented (area) and axis-aligned (point) lights. Both write per-channel EWNS deposit and apply a deposit edge-fade (`LightingDepositEdgeFade`, `ShaderFunctions.h`) — `smoothstep` over the outer 5% of the **deposit-texture** boundary, not the on-screen visible-area edge. Because the deposit texture is headroom-padded (`game::Camera::kfLightingHeadroomMultiplier` = 1.5x the visible area), that 5% band sits in the off-screen margin (~0.18 visible-widths beyond the frame), so the ramp completes before a light scrolls on-screen. This is intentional and artistic, not a regression from the headroom pre-size: lights fade in across the off-screen margin instead of popping to full brightness at the frame edge (an on-screen pop is jarring), and the visible area is deliberately *not* the fade reference. PointLight additionally rotates its texture sample about center, so it samples through the clamp sampler (a rotated texcoord exits [0,1]; AreaLight stays on the repeat sampler). A third depositor renders into the same pass: `Objects/HexShieldLighting.frag` (see [Objects/AGENTS.md](../Objects/AGENTS.md)).
- **VisibleLight.vert/.frag** - Instanced billboards for visible light effects with terrain-elevation fading above base height. Rotates texcoords in-shader with a manual clamp, since it stays on the repeat sampler.
- **LightingSpread.frag** - Radial gather pass run N times (runtime pass count); each pass reads the previous pass's textures, and all spread parameters interpolate from Start to End across the pass sequence. Gather pattern: rings with increasing per-ring direction counts, per-ring angular jitter, and per-fragment polar sample jitter (clustering bias); applies directionality (EWNS-weighted vs omnidirectional mix), distance falloff, decay, and terrain-elevation height attenuation above base height. Pass 0 reads the deposit texture through a hue-preserving per-EWNS Reinhard compress; every pass runs a second per-pass output compress. Emits two output sets: the accumulation chain (accumulation-decay add, carried to the next pass) and a separate pre-accumulation snapshot weighted by a per-pass combine-curve point — LightCombine consumes only the snapshots. Early-outs outside the on-screen window (texel world position reprojected into `f4VisibleArea`) plus a one-pass-gather margin, still carrying the accumulation chain forward without gathering — so steady-state cost ≈ the visible-area resolution, not the headroom texture, and far-spread spill past the margin clamps decay-attenuated at the window edge.
- **LightCombine.comp** - Sums the per-pass spread snapshots across all three channels, applies pass-count normalization and exposure scaling, then tone maps float16 to UNORM8 via the Uchimura curve; a blend parameter mixes per-channel tone mapping against luminance-preserving tone mapping (fast paths at the extremes). Also writes a precomputed ambient texture holding `0.25 * (E+W+N+S)` of the tone-mapped per-direction values, so consumers do one sample instead of three EWNS samples. Early-outs outside the visible window (+ bilinear margin), mirroring the spread early-out.
- **LightingTemporal.comp** - Temporal-accumulation pass run after LightCombine: reprojects each texel's world position into the previous frame's lighting area to fetch history, then EMA-blends the previous frame's four combine outputs (three directional + ambient) into the current grid to de-flicker the texel-grid rescale. Blend weight 1.0 (current-only) on the first frame so seeded history is never shown; reprojected UVs outside [0,1] are disocclusions and fall back to current. Mirrors ShadowTemporal / the smoke-wind previous-area reprojection.
- **LightingBlurH.comp / LightingBlurV.comp** - Separable Gaussian pre-blur of light-type textures. Radius/sigma packed into push constants; the vertical pass additionally applies a square-frame edge attenuation (Chebyshev max-of-abs distance, not radial) whose falloff exponent is packed in the push-constant fractional part.

## Architecture Notes

**Pipeline**: Deposit (MRT fragment) -> Spread x N (MRT fragment, parameters interpolated per pass, snapshots emitted) -> Combine (compute: sum snapshots, normalize, Uchimura tone map to UNORM + ambient) -> Temporal (compute: reproject + EMA-blend previous frame).

**Pre-blur**: After light-type textures load, H/V blur produces 2x-size RGBA8 render targets registered in the bindless array under a salted CRC (`originalCrc ^ "BLUR"`). Deposit shaders sample the blurred version; visible light sprites keep the original. Parameter changes trigger re-blur.

**Stable lighting area**: `f4LightingArea` is a camera-centered, world-sized-texel rectangle (shadow-style; see `GlobalUniforms.cpp` and the Graphics-hub CameraBase note). The deposit/spread/combine textures are allocated 1.5x the wanted pixel size via `kfLightingHeadroomMultiplier` as headroom; texel world size scales by the camera's rate-limited lighting-texel height, fixed at a settled eye height (snap-stable under pan) and rescaling only while tracking a zoom — the temporal pass de-flickers that rescale. The on-screen processed window holds a constant pixel size at every settled height (texels coarsen with zoom instead of cropping coverage); a fast zoom-out makes the lagging texel ramp cover less than the frustum, which naturally widens the processed window into the headroom until the ramp settles, and any overflow past the texture is sampled by terrain/water through the transparent-black CLAMP_TO_BORDER sampler (`mVkSamplerBorder`), so off-texture reads as no light.
