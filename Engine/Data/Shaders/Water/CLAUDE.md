# Water/ - Ocean Water Shaders

Vertex-animated ocean surface with Gerstner wave simulation, Fresnel-based skybox reflections, and depth-based coloring.

## Overview

Tessellated quad covering the visible area. A compute pre-pass bakes Gerstner displacement and the full Jacobian wave normal into two RGBA16F textures, one texel per vertex of the active LOD grid; the vertex shader reads them via `texelFetch`. Fragment shader composites depth-LUT color, skybox reflection, directional lighting, shadows, specular, and additive smoke. Normal and noise UVs use camera-relative positions combined with CPU-reduced double-precision origins to survive far-from-origin floating-point precision.

## Architecture Notes

- **Shore-fade asymmetry**: amplitude fade from terrain elevation is applied only to low-frequency waves; medium waves run at full amplitude everywhere.
- **Zoom-out amplitude fade**: CPU populates Gerstner geometric amplitudes (low- and medium-frequency) scaled by a camera-height factor that fades to zero between the default eye height and 2x. Applied after steepness clamps so the steepness invariant is preserved. Eliminates aliasing of submillimeter wave geometry at far zoom; shader is unaware. At the fade end (scale clamps to 0), CPU also writes 0 into the matching `iWater*Count` so the vertex shader's Gerstner loop short-circuits — no per-wave array entries are populated for that band.
- **Z flattening near shore / over land**: in the shore band (`-fWaterTerrainHeight ≤ terrain < 0`) world-Z is rescaled by `-terrain / fWaterTerrainHeight` so waves taper against the beach. Over land (`terrain ≥ 0`) the vertex shader skips Gerstner entirely and emits a flat vertex at world-Z=0 with up-normal — saves the wave evaluation since the scale would collapse it to 0 anyway. No vertex cull; the fragment shader's own early-out is disabled and it handles all elevations.
- **Varying conventions**: camera-relative initial position drives normal/noise UV math; fully-displaced world position drives lighting/shadow/smoke world-space lookups; a separate visible-area texcoord drives elevation, shadow, and object-shadow sampling.
- **Precision-safe sampling pact** (normals and color noise): `textureGrad` with derivatives of the camera-relative position and `fract()`-wrapped UVs — derivatives are taken before per-octave/per-sample scaling so mip selection stays stable across summed terms. Relies on the CPU-side reduced-origin modulus being chosen so per-sample size multipliers stay integer after wrap (see `Render/CLAUDE.md`). Continuous tweak sliders that feed these multipliers are constructed with a snap step so user adjustments cannot break the integer-product invariant. Normal source is BC5; Z reconstructed in-shader as `sqrt(saturate(1 - x*x - y*y))`.
- **Multi-sample normal composition**: Several independently-parameterized samples (each a runtime-selected atlas slot, own size / reduced origin / reduced time / octave stack) are weighted-summed then normalized — `normalize()` is scale-invariant so absolute weights only matter as ratios, and a zero-vector epsilon guards NaN when all weights resolve to zero. Per-sample weights are CPU-interpolated by a camera-zoom factor, letting close vs. far zoom favor different scales without a separate pipeline.
- **Gerstner normal — full Jacobian, not simplified**: the compute pre-bake builds tangent `T = ∂P/∂u` and bitangent `B = ∂P/∂v` accumulators (five summed scalars: a=Σ Q·ω·A·D.x²·sin, b=Σ Q·ω·A·D.x·D.y·sin, d=Σ Q·ω·A·D.y²·sin, g=Σ ω·A·D.x·cos, e=Σ ω·A·D.y·cos) and emits `normalize(cross(T, B))`. The GPU Gems Eq. 12 simplified form `N.z = 1 - Σ Q·ω·A·sin` is a first-order Taylor truncation that flips negative once the Finch invariant Σ Q·ω·A → 1, so `normalize()` produces downward normals at high steepness. The full Jacobian keeps the Q² cross-term `b²` and only fails at genuine surface-cusp formation — the physically correct boundary. Matches Catlike Coding / LYGIA.
- **Source-side wave-normal dampener**: a single global blend slider mixes the Gerstner-derived normal toward flat `(0,0,1)` before it feeds any downstream consumer. Acts at the source so lighting, reflection, EWNS, and specular all see the dampened normal consistently.
- **Displacement compute pre-bake**: a compute shader (`WaterDisplacement.comp`) runs once per frame before the WaterSkyboxOne pre-pass and writes Gerstner displacement and the full Jacobian normal into two RGBA16F textures, one texel per vertex of the active LOD grid. Grid dimensions arrive via `iWaterActiveQuadX/Y` so the texture is in 1:1 alignment with the vertex grid; the vertex shader reads with `texelFetch(..., gl_VertexIndex-derived i2Grid, 0)` — no filtering, no UV math. Per-frame layout cycles `kShaderReadOnly → kComputeReadWrite → kShaderReadOnly`. The compute shader sums both low and medium bands and short-circuits per-band when the respective amplitude is zero; both bands also run inside the shore Z-taper region. The water-mesh-recreate path (`DestroyFlags::kWaterMesh`, triggered by `gWaterShapeDetail`) recreates both the mesh and these textures together so dimensions stay paired.
- **Decoupled sampled-normal blends**: separately, the downstream wave-vs-sampled-normal blends for lighting and for skybox reflection sampling are independent, letting the two use different smoothness.
- **Skybox-specular lobe split**: the highest-frequency (One) lobe of the skybox specular is extracted into its own pre-pass shader that runs before the swapchain render pass at forced 4x MSAA + full sample-shading, resolves to a single-sample RT, and is sampled by the main water pass in screen space (`gl_FragCoord * f2InvFramebufferSize`). The main pass drops sample-shading and only runs the lower-power Two/Three lobes inline — those alias acceptably without per-sample shading. The pre-pass shader intentionally duplicates the main pass's eye-normal / multi-sample normal composition block verbatim so the two passes agree on screen-space alignment; any change to that block must be mirrored. A CPU tweak sizes the pre-pass RT relative to framebuffer extent (range 0.25..2.0).
- Fresnel uses a `(1 - cosθ)^4` falloff (not Schlick's canonical `^5`) — intentional visual tuning.
- Base-height projection projects the undisplaced world position down to the lighting plane for both EWNS lighting sampling and the smoke texcoord, keeping lighting stable under wave animation. EWNS sampling (3-sample directional, used by `WaterLighting`) optionally blends in a reflected projection — the eye→water ray reflected about the water normal, projected to the same base-height plane — to suggest sky/sun light bouncing off the surface. A separate additive ambient term samples the precomputed `mAmbientCombineTexture` once at the unreflected projection (replacing three EWNS samples) to mirror the terrain shader's ambient path; the smoke blend reuses the same single ambient fetch via `BlendSmokePrecomputed` (multiplied by 4 to recover the un-averaged sum), so smoke is decoupled from the wave normal entirely — matching `Terrain.frag`.
- Hue-preserving pow on base-height lighting samples blends luminance-based and average-based exponents via a mode uniform, applied before lighting.
- Time-of-day multiplier applies linearly after lighting's internal pow, scaling output without re-exponentiation.
- **Per-target sun/moon intensity scaling**: `f4SunColor` and `f4MoonColor` arrive at the shader unscaled by any global intensity. Each shader applies its own per-target sun and moon scalars at the read site, so terrain, water, objects, and smoke can be tuned independently without re-uploading colors. The water shader scales its sky-disk sun/moon contributions by the water-target scalars, and folds what was previously a post-multiplied moon-luma blend into the moon scalar applied upstream to the moon path. The EWNS-deposited paths (`WaterLighting()` and `AmbientLightingPrecomputed()`) are intentionally untouched. The moon floor color is hard-coded to a slight-blue-tint white at upload time, leaving slider control to the per-target moon scalar.
- **Sky-disk combine**: sun and moon contributions are combined channel-wise as `max(f4SunColor.xyz, f4MoonColor.xyz)` (variable `f3SunOrMoon`) rather than summed. The sun and moon share `f4SunMoonNormal` — they're the same celestial body alternating profiles — so summing during transitional overlap (which the moonrise/moonset window can be tuned wider than sunset/sunrise) produces unphysical doubling. The same `max` idiom is applied wherever sun/moon contributions combine in `Model.frag` (BRDF + IBL specular), `ShaderFunctions.h::SunLighting`, and the smoke ambient floors.
- **Sun/moon split shadow**: `f4SunColor` and `f4MoonColor` are uploaded as separate uniforms; the moon component bypasses the terrain ray-march shadow (object shadows + smoke volumetric attenuation still apply to both). The shadow is applied as a **scalar luminance-weighted blend** `(fShadowSun*W_sun + fShadowMoon*W_moon) / max(epsilon, W_sun+W_moon)` where the weights are Rec.601 luma over each color. A per-channel formulation would zero entire channels when `Sun.c + Moon.c` collapses to ~0 — notably morning sun has B=0 by design, and the skybox-cubemap mix in `f3LightingColor` breaks linearity in (Sun + Moon), so a per-channel divide cannot be undone by the colour multiplication. Scalar weighting is approximate but channel-safe.
- **Per-component sun/ambient shadow split (Affect Ambient slider)**: the per-target sunlight scalar carries `fSunScalar = mean(f3SunOrMoon)` and `fAmbientScalar = mean(f4AmbientColor)` separately rather than as a single summed scalar. At the shadow-apply site the sun-driven energy and the skybox specular keep the full `fEffectiveShadow`; the sky-ambient half is multiplied by `mix(1.0, fEffectiveShadow, fShadowAffectAmbient)` — same `(1-AA)+AA*fAmbientShadow` rule as `SunLighting()` in `ShaderFunctions.h`, reusing `fEffectiveShadow` directly because water's existing formula is byte-identical to `SunLighting()`'s `fAmbientShadow`. At slider=1 ambient is gated by the same shadow as the sun term, so AA=1 + occluded shadow drives the surface to black (modulo the additive EWNS+ambient deposit at lines 338/342, which is by design unshadowed because the deposit textures hold only emitter light).
- Output alpha encodes water transparency from terrain elevation, clamped to a minimum to keep deep water opaque.
