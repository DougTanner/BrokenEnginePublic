# Terrain/ - Terrain Rendering Shaders

Island terrain mesh rendering: an elevation prepass that fills the composite elevation G-buffers, plus a final compositing pass that samples per-island color / normal / AO / material-mask bindless arrays directly per-fragment.

## Overview

Two stages:

1. **Elevation prepass** — composites the bindless per-island heightmap array into an R16_SFLOAT (`shaders::keElevationFormat`) world-space elevation G-buffer, MAX-blending where island footprints overlap (chains pack by convex hull, so bounding rects may overlap underwater — tallest terrain wins per pixel; the target clears to the sea-floor elevation so single-island pixels are unchanged). Two pipelines run the same fragment shader: one fills the visible-area composite `mTerrainElevationTexture` (sampled by `Terrain.vert`/`Terrain.frag` here and by water / lighting / smoke / particle shaders), the other fills the shadow-area `mShadowElevationTexture` consumed by `Shadow.comp`. The vertex stage is shared from `Quads/QuadsAxisAlignedVisibleArea.vert`; only the fragment stage (`TerrainElevation.frag`) lives here.
2. **Compositing pass** — `Terrain.vert` + `Terrain.frag` draw the per-island Gaea-Mesher meshes. The vert transforms island-local XY into world space via the per-instance `AxisAlignedQuadLayout` (center + rotation) and forwards two UVs: a world-derived visible-area UV (for elevation / shadow / object-shadow / lighting / smoke / ambient samplers) and a rotation-independent island-local UV (for the per-island bindless color / normal / AO / mask arrays).

## Shaders

- **TerrainElevation.frag** — samples the per-island R16_SFLOAT heightmap (engine-meters relative to beach: 0 = beach, negative = water, positive = land) into the world-space elevation G-buffer. Undersea samples pass through a depth curve anchored at two fixed points (beach and sea floor); shallow water is pulled up toward beach with strength from a global compression uniform (1.0 = identity, smaller = stronger upward pull). Land samples pass through unchanged and skip the `pow`. Every downstream consumer inherits this single upstream depth shaping.
- **Terrain.vert** — transforms island-local mesh XY (DataPacker re-centered, Z stripped) into world space; re-derives world Z from the composite elevation G-buffer so the surface aligns pixel-perfectly with the water blend and shadows. Then samples this island's own heightmap (per-island bindless array) and sinks any vertex below the underwater zero-out threshold to the flat sea floor — otherwise a submerged mesh would rise to a taller overlapping neighbor's MAX height and draw its baked-black ocean terrain there. Forwards the island-local UV, the per-instance bindless slot, and the per-instance rotation `(cos, sin)`.
- **Terrain.frag** — samples per-island color / normal / AO / mask arrays via `nonuniformEXT(slot)` at the island-local UV. BC5 normal RG decoded `2x-1`, rotated by the forwarded `(cos, sin)`, Z reconstructed via `sqrt(1 - dot)`. Combines with sun lighting, terrain ray-march + object shadows, directional + ambient lighting, material detail blending, and smoke blending.

## Architecture Notes

- **Bindless slot, not instance index**: the per-island array index comes from `AxisAlignedQuadLayout::uiTextureSlot` (SSBO), forwarded by `Terrain.vert` — not `gl_InstanceIndex` — so one cell can mix island templates with no per-instance pipeline state. The per-island heightmap array is bound to the compositing pipeline as well as the two elevation/shadow pipelines so `Terrain.vert` can read each island's own elevation for the submerged-vert sink. Per-slot descriptor writes go through `TextureDescriptors::RegisterTextureBinding` (call sites in `IslandTerrainResidency.cpp`); the array/consumer-pipeline tuples self-register from the `kBindlessArrayConsumer`-flagged pipeline declarations in `PipelineManager.cpp`.
- **Direct SSBO field reads**: `Terrain.vert` reads `AxisAlignedQuadLayout` fields individually rather than via a whole-struct copy. This is stylistic, not a workaround — an earlier claim that glslang drops trailing fields on scalar-block-layout SSBO struct copies was investigated (no upstream glslang issue; SPIR-V disassembly at VulkanSDK 1.4.341.1 emits a complete whole-struct copy) and not substantiated. A whole-struct read would be equally valid.
- **Island rotation**: per-island textures are baked in island-local axes, so the island-local UV is rotation-independent by construction; `fRotation` only places the footprint in world space. The normal tangent is rotated by the forwarded `(cos, sin)` in `Terrain.frag`; reconstructed Z is rotation-invariant.
- **Material boundaries**: rock / sand / snow detail blending is driven by a per-island BC7 RGBA mask (R=rock, G=sand, B=snow, A=reserved) authored in Gaea, not by procedural color/elevation heuristics. Snow takes priority — snow-painted pixels suppress rock/sand blends proportionally, feed a sun-direction snow normal, and skip AO darkening so accumulated snow reads fresh.
- **Lighting**: sun lighting (moon bypasses the terrain ray-march shadow only — object shadows and smoke attenuation apply to both lights), plus EWNS directional and precomputed ambient lighting scaled by a terrain weight with a multiplicative/additive blend, with a below-base-height falloff and a time-of-day multiplier, finishing with the smoke blend (a lerp toward lit smoke color, not additive). A single base-height ambient fetch feeds both the ambient term and the smoke blend.
