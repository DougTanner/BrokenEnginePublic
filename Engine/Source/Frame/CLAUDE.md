# Frame - Core Game State and Fixed-Timestep Simulation

## Overview

Manages per-frame game state through a dual-phase update system (Interpolate for rendering, PostRender for logic) over a sparse grid of simulation cells. `game::Frame` aggregates engine base classes (`FrameInterpolateBase`, `FramePostRenderBase`) with game-specific extensions. Collections get automatic CRC, serialization, and comparison via compile-time type lists.

See also: [Frame Update Pipeline](../../../Documents/Architecture/FrameUpdatePipeline.md) — update this diagram if phase ordering changes.

## Key Classes

- **FrameInterpolateBase / FramePostRenderBase** - Split base classes for render-phase vs. logic-phase state. PostRender orchestrates sub-phases (Update, PreCollision, PostCollision, AreaDamage, Transfer, Destroy, Spawn) and owns determinism infrastructure (CRC chain, deterministic random, UUID streams).
- **FrameStaticData** - Immutable per-coord data (area bounds, per-cell island placement list, NavData) stored in `CoordFrames`. Each placement carries island CRC, world position, and rotation; the generator emits 1-4 placements per cell (rotated-AABB rejection sampling against the per-template footprint, see Projects/.../Frame/CLAUDE.md). Origin is sampled identically to every other cell — no special-case anchor. Server builds NavData from the placement list (rebasing each placement's template `NavContour` into world space using per-template `mfQuadFootprintX`/`mfQuadFootprintY`); clients receive it via network serialization.
- **FrameUtils** - Template helpers using `std::apply` + fold expressions to iterate all collections for CRC, serialization, and copy. Also exposes the shared movement model (drag/acceleration/max-speed with optional velocity-to-direction blending).
- **TimeStep** - Fixed-timestep accumulator with time scaling, clamp, and death-spiral auto-reduction. Also drives the client sim-ceiling clamp, not just stalls.
- **Collision** - Layer-based spatial partitioning (fixed zone grid) with discrete and swept sphere tests; swept falls through to discrete on already-overlapping. Per-pair masks must be bi-directional (asserted); same-layer collision unsupported. Results land in flat `thread_local` storage via prefix-sum spans.
- **AreaDamage** - Thread-local accumulator for explosion/AoE sources with linear falloff and category-bitmask filter; populated in PostCollision, queried in AreaDamage phase.
- **Alignments** - Sparse collision filtering via sorted flat vector with binary search; key is lower-id-first so `(A,B) == (B,A)`.
- **IslandTerrain** - CPU terrain queries (elevation, normals) shared by client and server. Holds one per-island template per kIsland manifest chunk, keyed by CRC. Each template is anisotropic (`mfQuadFootprintX`/`mfQuadFootprintY` in engine units, derived from asset world meters as `mfWorldFootprint{X,Y}Meters * kfMetersToUnits`); DataPacker auto-crops each island to its land bbox > 1 m, expanded to a multiple of `4 × kiElevationDivisor` so BC encoding and elevation downsample stay block-aligned per axis. Renderer + sim queries read both per-template values. Heightmaps store absolute elevation in meters (R32_SFLOAT) — pixel value 0 is sea level / beach, negative is underwater, positive is land. The engine reads samples directly with no runtime height or water-depth multipliers (DataPacker has already scaled and offset the values). Elevation/normal hot paths look up the queried coord in `game::gpGame->mCoordFrames` and walk that cell's placement list, transforming the query into each placement's local space before sampling the matching template. `GlobalNormal` uses a fixed finite-difference step (in engine units); each tap routes through `GlobalElevation` so the same baseline works across templates at different scales. Every template builds its own `NavContour` server-side (UV-space topology), so multi-template cells produce per-placement nav data; clients never walk the heightmap for nav. Client owns deterministic, on-demand CRC-to-bindless-texture-slot assignment for terrain G-buffer routing — slots are minted lazily as subscription-driven static data arrives, with slot 0 permanently reserved as a neutral programmatic placeholder (format-matched uncompressed textures owned by `TextureManager`, never adopted by a real island). First-mint for any real island routes through the slot-0 fallback until its disk textures resolve. Each template additionally carries a fixed-at-boot index into the sorted CRC list (assigned in `IslandTerrain` ctor right after the sort) — this index, decoupled from the lazy texture slot, addresses the per-template SSBO range and indirect-draw slot in `Islands`, and never changes after boot. Elevation (R32_SFLOAT) bypasses the lazy-texture-chunk pipeline entirely: it's uploaded directly from the in-memory heightmap already resident in the kIsland chunk (loaded at boot), skipping a redundant ~11 MB disk read per island that previously caused multi-second visible-load lag. The GPU image lives on `IslandTemplate::mElevationTexture` (template-owned, no `mTextureMap` entry, no chunk CRC); descriptor patching uses `TextureDescriptors::UpdateArrayBindingsForKey` — the array-only sibling of the CRC-keyed update path — and is deferred to the post-fence-wait safety window inside `RestorationSweep`. Elevation is permanently resident (mesh-buffer policy, never evicted). Per-template Gaea2 terrain meshes are likewise permanently resident: vertex/index counts come from the manifest synchronously and are shared (not client-only) so `Islands` can bake them into per-template indirect commands at boot; the GPU mesh buffers are uploaded once in `IslandTerrain::CreateClientMeshBuffers` (called from `Islands` ctor, after VMA exists, before terrain CB record) and released ahead of Graphics teardown via `ReleaseGpuResources` at the kSurface destroy tier. This boot-time-then-frozen mesh policy is what permits the record-once CB invariant — mesh buffers can't be created lazily on first visit. `Main` therefore runs `WaitForElevationMaps` before `Graphics` is constructed. Device-loss recovery defensively re-creates elevation if its `VkImage` is null. Client tracks per-template GPU residency, an each-frame-recomputed reference count from active placements, and a render-frame last-used stamp; eviction and restoration sweeps bracket `TextureManager::ProcessPendingTextures` in `RenderGlobal` post-fence-wait, with non-resident slots dropping to the slot-0 fallback once a grace window elapses. DataPacker offsets every island's heightmap by a per-bake `fBeachOffsetMeters = fSeaLevelNormalized * elevationMeters` (sea level read from the archetype's Sea node `Level`, defaulting to `kfGaeaSeaLevelDefault = 0.1f`), so sample == 0 is the beach line and the sea floor sits at `-fBeachOffsetMeters` — depth scales per island (100 m island at Level 0.1 → -10 m floor); open-ocean cells (no island placement) fall back to a fixed global floor (`common::kfOceanDepthMeters`). DataPacker densifies Gaea's mesh adaptively around the shoreline (triangles in a symmetric vertical band straddling sample == 0 are subdivided to a sub-meter XY edge), so uploaded vertex buffers carry far more triangles near the beach than inland or offshore. Island assets are now 1 m = 1 engine unit (`kfMetersToUnits = 1.0f`); the rest of the engine still runs in unit-less units pending a follow-up conversion pass.
- **NavBuild / NavQuery** - Visibility-graph pathfinding over per-cell NavData. Direct LOS fast path with A* fallback. **Bump `kiNavDataVersion` when changing NavData content** (feeds into `Frame::kiVersion` for save compatibility).

## Architecture Notes

- **CRC system**: Single shared CRC excludes both client-only and server-only fields, cached after update. Drives cross-build determinism validation and reconciliation fast-path. `ServerCollections()` is the cross-build-shared subset walked by CRC, `ServerRead`, and `LogDifferences`; client-only collections stay out of determinism.
- **Collection registration**: `Collections()` tuple size is `static_assert`-locked to each base's `kCollectionCount`, and the two bases must agree. When adding a Collection pair, update both `kCollectionCount` constants and (if shared) `ServerCollections()` alongside the `Collections()` tuple.
- **Client/server split**: Visual-only collections gated by `#ifdef BT_CLIENT`.
- **thread_local lazy-init**: `Collision` and `AreaDamage` thread_local vectors MUST start empty — constructors run during `mi_process_init` before the allocator is ready. First-use resize and overflow growth wrap realloc in `ScopedSuppressAllocationTracking` and (on overflow) `DEBUG_BREAK` naming the preallocate constant to raise.
- **No transient metadata in Frame structs** — only logical state belongs here; derived data goes in lookup infrastructure.
