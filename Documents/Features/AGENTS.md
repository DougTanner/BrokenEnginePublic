# Features

Plans for work that adds a capability the engine does not already have. Feature plans are tracked Markdown documents, but execution is manual: WorktreeCli never validates, claims, stores locks for, or mutates `Documents/Features`.

Use existing subject-area subdirectories and retain clear scope, invariants, and acceptance criteria. If work is a refactor or bugfix rather than a new capability, place it in `Documents/Plans`, the only tree covered by `/next-plan`.
