# Investigations

Non-executable reference material: findings records, series overviews, and investigations that present options rather than a decision-complete implementation. WorktreeCli never validates, claims, stores locks for, or changes `Documents/Investigations`.

Work blocked on another change is a Plan — it belongs in `Documents/Plans` with a `dependsOn` edge. Work blocked on a decision belongs here until the decision exists; it earns a Plan by moving to `Documents/Plans/<area>/` with the metadata line that must be the very first bytes of the file.

Use existing subject-area subdirectories.
