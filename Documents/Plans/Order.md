# Plan Execution Order

All refactor and bugfix plans — debt reduction that doesn't add a new engine capability — sorted by score (lowest = highest priority).

Score = Effort − Impact + Risks (lower = higher priority)

`Tier` column is an informal size/risk descriptor (**Quick Win** / **Small** / **Medium** / **Large** / **Architectural**); it does not affect score or ordering.

Counterpart: `Documents/Features/Order.md` holds brand-new additions. See `Documents/AGENTS.md` for the distinction. Scores are not comparable across the two files — they were originally derived from a single sort and then split.

This file reflects only the CURRENT set of live plans. It is not a changelog — landed/dropped plans, and the sessions that produced them, are not recorded here.
