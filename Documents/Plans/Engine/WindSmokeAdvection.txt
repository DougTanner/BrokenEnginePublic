Fix: Wind doesn't push low-value smoke
=========================================

Context
-------
Low-value (old, diffused) smoke is barely affected by wind. Only recently-deposited high-value smoke visibly moves. Two root causes in SmokeSpreadCommon.h:

1. Wind displacement is entirely noise-gated (line 34): f2WindDisplacement = noiseScale * abs(fWindNoiseSample) * f2WindRescaled. When fWindNoiseSample is near zero (common), displacement is zero regardless of wind strength. High-value smoke survives enough frames to get pushed when noise is favorable; low-value smoke decays away first.

2. Sample blending fails in smooth fields (lines 38-39): Wind works by blending between a base sample and a wind-displaced sample. In uniform density fields (old diffused smoke), both samples return nearly the same value, so the blend produces no visible movement.

Fix
---
Add a direct wind advection offset to the base sampling coordinate -- a non-noise-dependent wind push that physically shifts where each texel samples from. Works even in uniform density fields. The existing noise-modulated displacement stays for visual variation.

New tunable: fWindSmokeAdvection (default 0.4, range 0.0-2.0)
