# Combine Crc() and ServerCrc() into single Crcs() method

## Context

`Crc()` and `ServerCrc()` exist as separate methods at every frame level, duplicating scalar field
checksumming. Refactor into a single `Crcs()` method that computes both simultaneously, supported by
a three-parameter `common::Crc()` helper that XORs a value's CRC into two checksums at once.

`Frame::Crc()` and `Frame::ServerCrc()` are retained as thin wrappers around `Crcs()` because
`DifferenceStream.h` is a template requiring a `.Crc()` interface on its `SAVED_TYPE`.

## 1. Add three-parameter `common::Crc()` overload

**File**: `Common/Utils.h` (after line 141, after XMVECTOR Crc overload)

Add:
```cpp
template <typename T>
void Crc(const T& rValue, crc_t& rCrc, crc_t& rServerCrc)
{
	crc_t c = Crc(rValue);
	rCrc ^= c;
	rServerCrc ^= c;
}
```

For pre-computed `crc_t` values (e.g. `randomEngine.Crc()`, `alignments.Crc()`), use manual XOR at each call site:
```cpp
crc_t c = randomEngine.Crc();
crc ^= c;
serverCrc ^= c;
```

std::pair<common::crc_t, common::crc_t> FrameInterpolate::Crcs(const FrameInterpolate& rCurrent)
{
	auto [crc, serverCrc] = static_cast<const engine::FrameInterpolateBase&>(rCurrent).Crcs();

	common::Crc(rCurrent.gameFlags, crc, serverCrc);
	common::Crc(rCurrent.fSpawnTimer, crc, serverCrc);

			serverCrc ^= engine::ServerCollectionCrc(cols);
		}()), ...);
	}, GameInterpolateCollections(rCurrent));

	return {crc, serverCrc};
}

	auto [postCrc, postServerCrc] = FramePostRender::Crcs(postRender);
