CHANGE 3: R5 — Replace sResults unordered_map with pre-allocated flat structure
================================================================================

Goal: sResults is std::unordered_map<uint64_t, std::vector<CollisionResult>> causing per-frame
heap allocations. Replace with a flat pre-allocated structure.

Access pattern analysis:
  - Collide() calls sResults.clear() once per frame
  - CollideLayerPair() calls sResults.try_emplace(key).first->second.push_back(result) to record
  - HasCollision() calls sResults.contains(key) — just existence check
  - GetCollisions() calls sResults.find(key) — returns pointer to vector

Design: Two parallel arrays:
  1. A flat array of CollisionResult entries (all results contiguous)
  2. A per-key index: for each (layer, objectIndex) pair, store offset+count into the flat array

Since keys are (layerIndex << 32 | objectIndex), and we know max layers (kiCollisionLayerPreallocate=16)
and can bound max objects per layer, we can use a direct-mapped array.

However, the object count per layer varies and can be large. A simpler approach: use a hash map
that doesn't heap-allocate. But we want zero heap allocations.

Best approach: Two flat vectors with counts, similar to how the rest of the codebase works.

  - sResultEntries: flat vector of CollisionResult, pre-allocated
  - sResultKeys: flat vector of {uint64_t key, int64_t offset, int64_t count}, pre-allocated
  - Record: append to sResultEntries; on first collision for a key, add to sResultKeys.
    On subsequent collisions for same key, just increment count (entries are contiguous per key
    IF we process all collisions for one A object before moving to the next).

Wait — the current code records for both A and B in the same inner loop iteration. So key A's results
are contiguous within one zone iteration, but key B results are interleaved. This breaks contiguity.

Alternative: Record A-side and B-side results separately, then for queries, scan the key index.
But that changes too much.

Simpler approach that preserves the current recording pattern:
  - sResultEntries: flat array of CollisionResult
  - sResultOffsets: parallel array indexed by a key lookup, storing {offset, count} into sResultEntries
  - For key lookup without hashing: since each collision is recorded for BOTH sides, and keys are
    (layerIndex, objectIndex), we can use a two-level array: per-layer offset + per-object slot.

Actually, the simplest correct approach: Keep the same logical structure but use pre-allocated
flat storage with manual management instead of std::unordered_map.

Design:
  - CollisionResultSpan { int64_t iOffset; int64_t iCount; } — offset+count into flat results array
  - sResultEntries: thread_local std::vector<CollisionResult> — flat, pre-allocated
  - siResultEntryCount: thread_local int64_t — current count
  - For key lookup: thread_local std::vector<CollisionResultSpan> per layer, indexed by object index.
    But layer count and object count vary per frame.

Simplest viable design using the existing data:
  Each layer has a known iCount at registration time. We can allocate a per-layer array of
  CollisionResultSpan after all layers are registered. But layers are registered incrementally
  and results are queried after Collide().

Final design — two-level flat map:
  - After SetupZones (when all layers are known), allocate a flat array of CollisionResultSpan
    sized to sum(layer.iCount for all layers), with a per-layer offset table.
  - sLayerOffsets[layerIndex] = starting offset in the spans array for that layer
  - sResultSpans[sLayerOffsets[layerIndex] + objectIndex] = {offset, count} into sResultEntries

This gives O(1) lookup by (layerIndex, objectIndex) with zero hashing.

void Collision::AllocateResultStorage()
{
	// Calculate total object count across all layers for span allocation
	int64_t iTotalObjects = 0;
	for (int64_t i = 0; i < siLayerCount; ++i)
	{
		sLayerBaseOffsets[static_cast<size_t>(i)] = iTotalObjects;
		iTotalObjects += sLayers.at(static_cast<size_t>(i)).iCount;
	}

	// Lazy pre-allocation for result entries
	if (sResultEntries.empty())
	{
		ScopedSuppressAllocationTracking suppressAllocationTracking;
		sResultEntries.resize(static_cast<size_t>(kiCollisionResultPreallocate));
	}
	siResultEntryCount = 0;

	// Allocate/grow spans array
	if (sResultSpans.empty())
	{
		ScopedSuppressAllocationTracking suppressAllocationTracking;
		sResultSpans.resize(static_cast<size_t>(kiCollisionResultSpanPreallocate));
	}
	if (iTotalObjects > static_cast<int64_t>(sResultSpans.size()))
	{
		ScopedSuppressAllocationTracking suppressAllocationTracking;
		sResultSpans.resize(static_cast<size_t>(iTotalObjects));
	}

	// Reset spans
	for (int64_t i = 0; i < iTotalObjects; ++i)
	{
		sResultSpans.at(static_cast<size_t>(i)) = {-1, 0};
	}
	siResultSpanCount = iTotalObjects;
}

IMPORTANT: This design assumes results for a given key are CONTIGUOUS in sResultEntries.
This holds because: for a given A object, all B collisions are recorded sequentially within
the inner loop, so rSpanA entries are contiguous. For B objects, each B gets its result
appended as it's encountered; if B collides with multiple A objects across different zones,
its results ARE still contiguous because pTestedBGeneration prevents re-testing. Each B-A
pair is recorded exactly once, and for a given B across multiple A objects, the B-side
records are NOT contiguous (they're interleaved with A-side records for different A objects).

This breaks the contiguity assumption for B-side results. We need a different approach.

REVISED DESIGN: Use workbuffer-based temporary storage during CollideLayerPair, then copy
results into per-object spans after all pairs are processed. But results outlive the call.

REVISED DESIGN 2: Keep the flat results array but change the query API. Instead of returning
a contiguous span, collect results during query by scanning.

Actually, re-examining the issue: B-side results for a single B object ARE contiguous IF that
B object only collides with A objects that are processed in sequence within the same zone
iteration. But B can appear in multiple zones and collide with different A objects in each.
However, pTestedBGeneration ensures each A-B pair is tested exactly once. The issue is that
when A=0 collides with B=5, we write entries [A0,B5] then [B5,A0]. Then when A=1 collides
with B=5, we write [A1,B5] then [B5,A1]. B5's span starts at the first [B5,A0] entry, but
[B5,A1] is not adjacent — [A1,B5] is in between.

Fix: Record all results in a single flat array, but use a SEPARATE results array for A-side
and B-side? No, that changes the query API.

SIMPLEST CORRECT FIX: Use per-object vectors that are pre-allocated but not heap-allocating.
OR: Accept that results for a given key may not be contiguous by using an indirect index.

ACTUAL SIMPLEST FIX: Two-pass approach.
  Pass 1: CollideLayerPair records collisions into a flat "pending" array on the workbuffer.
  Pass 2: After all CollideLayerPair calls, sort/bucket pending results by key into sResultEntries.

This is clean but adds a sort step. However, the collision count is typically small.

ALTERNATIVE: Just pre-allocate the vectors inside the map to avoid per-frame heap allocation.
Use a custom allocator or pool. But that's complex.

PRAGMATIC SOLUTION: Replace std::unordered_map with a flat hash map that uses pre-allocated
storage. But this still has the non-determinism concern.

FINAL DECISION: Two-pass approach using workbuffer for pending results.

void Collision::Collide(const Alignments& rAlignments, FXMVECTOR vecArea)
{
	ScopedCpuProfile scopedCpuProfile(game::kCpuTimerPostRenderCollide);

	// Build zone acceleration structure
	SetupZones(vecArea);

	// Push workbuffer for pending collision results
	// Reserve space: estimate max collisions as sum of all layer counts (generous upper bound)
	int64_t iMaxPending = 0;
	for (int64_t i = 0; i < siLayerCount; ++i)
	{
		iMaxPending += sLayers.at(static_cast<size_t>(i)).iCount;
	}
	iMaxPending *= 2;  // Each collision records 2 entries (A-side and B-side)
	PendingCollisionResult* pPending = common::gpThreadLocal->mWorkbuffer.PushBuffer<PendingCollisionResult*>(
		iMaxPending * static_cast<int64_t>(sizeof(PendingCollisionResult)));
	int64_t iPendingCount = 0;

	// Process all layer pair zones
	for (int64_t i = 0; i < siLayerPairCount; ++i)
	{
		CollideLayerPair(rAlignments, sLayerPairZones.at(static_cast<size_t>(i)), pPending, iPendingCount);
	}

	// Bucket pending results into flat contiguous storage
	AllocateResultStorage();

	// Count results per key
	for (int64_t i = 0; i < iPendingCount; ++i)
	{
		const PendingCollisionResult& rPending = pPending[i];
		int64_t iSpanIndex = sLayerBaseOffsets[static_cast<size_t>(rPending.iLayerIndex)] + rPending.iObjectIndex;
		++sResultSpans.at(static_cast<size_t>(iSpanIndex)).iCount;
	}

	// Assign offsets (prefix sum)
	int64_t iOffset = 0;
	for (int64_t i = 0; i < siResultSpanCount; ++i)
	{
		CollisionResultSpan& rSpan = sResultSpans.at(static_cast<size_t>(i));
		if (rSpan.iCount > 0)
		{
			rSpan.iOffset = iOffset;
			iOffset += rSpan.iCount;
			rSpan.iCount = 0;  // Reset for fill pass
		}
	}

	// Grow result entries if needed
	if (iOffset > static_cast<int64_t>(sResultEntries.size()))
	{
		ScopedSuppressAllocationTracking suppressAllocationTracking;
		sResultEntries.resize(static_cast<size_t>(iOffset));
	}
	siResultEntryCount = iOffset;

	// Fill results
	for (int64_t i = 0; i < iPendingCount; ++i)
	{
		const PendingCollisionResult& rPending = pPending[i];
		int64_t iSpanIndex = sLayerBaseOffsets[static_cast<size_t>(rPending.iLayerIndex)] + rPending.iObjectIndex;
		CollisionResultSpan& rSpan = sResultSpans.at(static_cast<size_t>(iSpanIndex));
		sResultEntries.at(static_cast<size_t>(rSpan.iOffset + rSpan.iCount)) = rPending.result;
		++rSpan.iCount;
	}

	common::gpThreadLocal->mWorkbuffer.Pop();  // Release pending results
}

void Collision::AllocateResultStorage()
{
	// Calculate total object count across all layers
	int64_t iTotalObjects = 0;
	for (int64_t i = 0; i < siLayerCount; ++i)
	{
		sLayerBaseOffsets[static_cast<size_t>(i)] = iTotalObjects;
		iTotalObjects += sLayers.at(static_cast<size_t>(i)).iCount;
	}

	// Allocate/grow spans array
	if (sResultSpans.empty())
	{
		ScopedSuppressAllocationTracking suppressAllocationTracking;
		sResultSpans.resize(static_cast<size_t>(kiCollisionResultSpanPreallocate));
	}
	if (iTotalObjects > static_cast<int64_t>(sResultSpans.size()))
	{
		ScopedSuppressAllocationTracking suppressAllocationTracking;
		sResultSpans.resize(static_cast<size_t>(iTotalObjects));
	}

	// Reset spans
	for (int64_t i = 0; i < iTotalObjects; ++i)
	{
		sResultSpans.at(static_cast<size_t>(i)) = {-1, 0};
	}
	siResultSpanCount = iTotalObjects;
}

thread_local std::vector<AreaDamageSource> AreaDamage::sSources;
thread_local int64_t AreaDamage::siSourceCount = 0;

void AreaDamage::Add(const AreaDamageSource& rSource)
{
	int64_t iIndex = siSourceCount;
	if (sSources.empty())
	{
		// Heap: one-time per-thread pre-allocation (thread_local vectors start empty to avoid allocating during mi_process_init)
		ScopedSuppressAllocationTracking suppressAllocationTracking;
		sSources.resize(kiAreaDamageSourcePreallocate);
	}

	if (siSourceCount >= static_cast<int64_t>(sSources.size()))
	{
		Log("AreaDamage: sSources overflow (count: {}, capacity: {}). Increase kiAreaDamageSourcePreallocate in AreaDamage.h", siSourceCount, sSources.size());
		DEBUG_BREAK();
		sSources.resize(siSourceCount * 2);
	}
	sSources.at(static_cast<size_t>(iIndex)) = rSource;
	++siSourceCount;
}

float AreaDamage::Get(FXMVECTOR vecPosition, uint16_t uiCategoryMask, XMVECTOR& rvecClosestSource)
{
	float fTotalDamage = 0.0f;
	float fClosestDistance = std::numeric_limits<float>::max();
	rvecClosestSource = vecPosition;

	for (int64_t i = 0; i < siSourceCount; ++i)
	{
		const AreaDamageSource& rSource = sSources.at(static_cast<size_t>(i));
		// Filter by category
		if ((rSource.uiCategory & uiCategoryMask) == 0)
		{
			continue;
		}

		// Calculate distance
		XMVECTOR vecDiff = XMVectorSubtract(vecPosition, rSource.vecPosition);
		float fDistance = XMVectorGetX(XMVector3Length(vecDiff));

		// Skip if outside radius
		if (fDistance >= rSource.fRadius)
		{
			continue;
		}

		// Track closest source
		if (fDistance < fClosestDistance)
		{
			fClosestDistance = fDistance;
			rvecClosestSource = rSource.vecPosition;
		}

		// Linear falloff: full damage at center, zero at edge
		float fFalloff = 1.0f - (fDistance / rSource.fRadius);
		fTotalDamage += rSource.fDamage * fFalloff;
	}

	return fTotalDamage;
}

void AreaDamage::Clear()
{
	siSourceCount = 0;
}
