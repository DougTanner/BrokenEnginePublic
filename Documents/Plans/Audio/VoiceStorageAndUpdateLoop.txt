Voice Storage and Update Loop Improvements
============================================
Optimize AudioManager voice storage, reduce per-frame overhead in Apply3dVolume,
eliminate O(N*M) validity checks, and clean up StaticVoice class.

Finding [M6]: Replace unordered_map with flat storage for mStaticVoices
Status: MODIFIED
Replace std::unordered_map<sound_t, StaticVoice> with a fixed-capacity flat array.
Use a simple linear scan for lookups (voice counts are small, bounded by kiMaxStaticVoices).
StaticVoice is move-only, so use a std::array + count pattern.

  File: Engine/Source/Audio/AudioManager.h
    - Line 67: Replace:
        std::unordered_map<sound_t, StaticVoice> mStaticVoices;
      With:
        int64_t miStaticVoiceCount = 0;
        std::array<StaticVoice*, kiMaxStaticVoices> mStaticVoices {};

      NOTE: StaticVoice is move-only with a deleted default constructor and contains
      an XMVECTOR (16-byte alignment). Using raw pointers to heap-allocated StaticVoice
      objects avoids alignment issues with std::array<StaticVoice, N> and the deleted
      default constructor problem. Alternatively, we could add a default constructor
      and use std::optional<StaticVoice> but that adds complexity.

      REVISED APPROACH: Add a default constructor to StaticVoice, use a flat array of
      StaticVoice with a validity flag (mId being valid), and a count.

      SIMPLEST APPROACH: Keep std::vector<StaticVoice> but reserve kiMaxStaticVoices
      capacity up front. This gives flat storage (contiguous memory, good cache locality)
      without needing default constructors. The vector won't reallocate since we cap at
      kiMaxStaticVoices.

Finding [M8]: O(1) validity check using idToIndexMap
Status: CONFIRMED
Lines 409-412 do O(N) scan of rSoundsPostRender.puiIds for each static voice.
SoundsInterpolate has idToIndexMap (unordered_map<sound_t, int64_t>) which supports
.contains() in O(1). Since paired collections share the same IDs, checking
idToIndexMap is equivalent.

  File: Engine/Source/Audio/AudioManager.cpp
    - Lines 408-412: Replace the inner loop:
        bool bValid = false;
        for (int64_t i = 0; i < rSoundsPostRender.iCount; ++i)
        {
            bValid |= rSoundsPostRender.puiIds[i] == rVoice.mId;
        }
      With:
        bool bValid = rSoundsInterpolate.idToIndexMap.contains(rVoice.mId);

Finding [L8]: Merge three loops into single pass
Status: REJECTED
The three loops iterate different collections:
  1. Lines 404-446: Iterates mStaticVoices (engine-side voice map)
  2. Lines 449-476: Iterates rSoundsPostRender (frame sound array) to add new voices
  3. Lines 479-495: Iterates rSoundsPostRender (frame sound array) to sync properties
Loops 2 and 3 both iterate rSoundsPostRender and could be merged, but loop 1
iterates a different collection entirely. Merging loops 2+3 is trivial but the
proposed "single pass" across all three is not possible without making the code
more complex. However, merging loops 2 and 3 is worth doing since they share
the same iteration range.

  File: Engine/Source/Audio/AudioManager.cpp
    - Merge the "add new voices" loop (449-476) and "sync volume/positions" loop
      (479-495) into a single loop over rSoundsPostRender:

      for (int64_t i = 0; i < rSoundsPostRender.iCount; ++i)
      {
          sound_t id = rSoundsPostRender.puiIds[i];
          int64_t iIndex = rSoundsInterpolate.IdToIndex(id);
          float fVolume = rSoundsInterpolate.pfVolumes[iIndex];

          // Find existing voice
          StaticVoice* pExistingVoice = nullptr;
          for (StaticVoice& rExisting : mStaticVoices)
          {
              if (rExisting.mId == id)
              {
                  pExistingVoice = &rExisting;
                  break;
              }
          }

          if (pExistingVoice != nullptr)
          {
              // Sync existing voice
              pExistingVoice->mfVolume = fVolume;
              pExistingVoice->mfPitch = rSoundsInterpolate.pfPitches[iIndex];
              pExistingVoice->mVecPosition = rSoundsInterpolate.pVecPositions[iIndex];
              pExistingVoice->mVecVelocity = rSoundsInterpolate.pVecVelocities[iIndex];
              continue;
          }

          // Add new voice
          if (fVolume <= 0.0f)
          {
              continue;
          }
          if (static_cast<int64_t>(mStaticVoices.size()) >= kiMaxStaticVoices)
          {
              continue;
          }

          common::crc_t uiCrc = rSoundsInterpolate.puiCrcs[iIndex];
          IXAudio2SourceVoice* pVoice = nullptr;
          if (StaticVoice::LoadXAudio2SourceVoice(mpAudioEngine.get(), pVoice, uiCrc, false, true))
          {
              float fPitch = rSoundsInterpolate.pfPitches[iIndex];
              float fFadeOutTime = rSoundsInterpolate.pfFadeOutTimes[iIndex];
              XMVECTOR vecPosition = rSoundsInterpolate.pVecPositions[iIndex];
              XMVECTOR vecVelocity = rSoundsInterpolate.pVecVelocities[iIndex];
              mStaticVoices.push_back(StaticVoice(pVoice, id, uiCrc, fVolume, fPitch, fFadeOutTime, vecPosition, vecVelocity));
          }
      }


Order of Operations
===================
1. [L2] Remove virtual from StaticVoice destructor (standalone, no dependencies)
2. [H3 + M6] Add kiMaxStaticVoices constant, replace unordered_map with vector
   (these are coupled -- the cap needs the flat storage, the flat storage enables the cap)
3. [M8] Replace O(N*M) validity check with idToIndexMap.contains()
4. [L8 partial] Merge add-new and sync loops into single pass over rSoundsPostRender
5. [M7] Cache mastering voice channel count
