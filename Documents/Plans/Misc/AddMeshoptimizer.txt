Add meshoptimizer to DataPacker
================================

Context
-------
The DataPacker has a custom vertex deduplication pass (~65 lines, hash-map based) but no vertex cache optimization, overdraw optimization, or LOD generation. meshoptimizer (MIT, by Arseny Kapoulkine) is the industry-standard open-source mesh optimization library used by Godot, glTF tools, and many AAA pipelines.

Why
---
- Replace custom vertex dedup with meshopt_optimizeVertexCacheStrip (also deduplicates)
- Add vertex cache optimization (meshopt_optimizeVertexCache) — reorders triangles for GPU post-transform cache, directly improves rendering performance
- Add overdraw optimization (meshopt_optimizeOverdraw) — reorders triangles to reduce pixel overdraw
- Optionally add LOD generation (meshopt_simplify) for future use
- MIT license, single-header-friendly, no dependencies

Changes
-------

1. ThirdParty/
   - Add meshoptimizer as a git submodule

2. DataPacker vcxproj
   - Add meshoptimizer source files to project filters

3. DataPacker/Source/ExportJobs/ExportSceneVertices.cpp
   - Replace the custom std::unordered_map vertex dedup (~lines 270-333) with:
     a. meshopt_generateVertexRemap() — produces remap table
     b. meshopt_remapVertexBuffer() + meshopt_remapIndexBuffer() — apply remap
   - After dedup, add optimization passes:
     a. meshopt_optimizeVertexCache() — reorder indices for GPU cache
     b. meshopt_optimizeOverdraw() — reorder for reduced overdraw
     c. meshopt_optimizeVertexFetch() — reorder vertices for sequential access

4. DataPacker/Source/ExportJobs/ExportScene.cpp
   - Verify the optimized index/vertex buffers are written correctly to the pack format
   - Both 16-bit and 32-bit index paths must use the optimized data

Notes
-----
- Vertex cache optimization provides measurable GPU performance improvement at zero runtime cost
- The optimization happens offline in the DataPacker, so processing time increase is acceptable
- meshoptimizer works with any vertex format via stride parameter — compatible with ModelVertex
- LOD generation can be added later as a separate feature
