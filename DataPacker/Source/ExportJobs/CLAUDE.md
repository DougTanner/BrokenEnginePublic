# `DataPacker/Source/ExportJobs/`

Asset-specific processors that convert raw files into cached binary chunks.

## ExportJob Pipeline

Abstract base owns dirty-checking and cache I/O; derived classes only implement `Export()` (and sometimes `CheckDirty()` / `CleanupOnFailure()`).

- **Cache layout**: `.chunk` = magic + version + `ChunkHeader` + aligned data. A sibling `.txt` stores the input's `last_write_time` so `CheckDirty` survives restores that preserve filesystem timestamps.
- **Version convention**: `GetVersion()` returns `ExportJob::Version(N)` (folds in `sizeof(common::ChunkHeader)`) so header-layout changes auto-invalidate caches. `ExportShader` passes `Version(14 + VK_HEADER_VERSION)` to force re-export on SDK upgrades.
- **Allocation contract**: each `Export()` calls `AllocateHeaderAndData` exactly once; the base populates magic/crc/flags/path afterward.
- **Clean path**: `RunExport()` skips `Export()` and streams cached bytes back when not dirty.
- **Per-job workbuffer**: `RunExport()` constructs a `common::ThreadLocal` — jobs run on worker threads with isolated `gpThreadLocal->mWorkbuffer`.
- **Intermediate cleanup**: jobs that produce sidecar files track them and override `CleanupOnFailure()` to unlink on throw.

## Handles() and ChunkFlags

Static `Handles(directory_entry) -> optional<ChunkFlags_t>` decides whether a processor claims a path and tags the resulting chunk (stage bits for shaders, cubemap bit for `[C]` textures, raw-passthrough for files under `Raw/`).

## Two-Phase Pipeline

Scene and Islands run a pre-export phase emitting intermediates consumed by the main phase:

- **Islands**: each island lives in its own folder. The Gaea pre-pass (see `../CLAUDE.md`) reads `Island.json` (strictly five required keys: `archetype`, `seed`, `widthMeters`, `elevationMeters`, `texturePixels` — any missing key throws; the legacy `mips` key throws a migration error; `texturePixels` must be a multiple of `4 * kiElevationDivisor` so both the color resolution and the 4×-downsampled elevation resolution remain BC-block-aligned) and the resolved `.terrain` archetype, then invokes Gaea once at `texturePixels` resolution into a single `Intermediates/` subfolder, writing `.r32` (FloatRaw32) elevation, `.r16` (UshortRaw16) AO, `.png` (8-bit sRGB) color, and `.exr` (float linear) normals. Any remaining Island.json keys (after the five required ones are consumed) are forwarded to Gaea via `--vars` so a single template can produce islands at multiple physical scales. `widthMeters`/`elevationMeters`/`seed` are special-cased: Gaea's `--vars` can't reach the archetype's intrinsic `Terrain.{Width,Height}`, and its `--seed` CLI flag only mixes a global seed into per-node randomness (doesn't override). The pre-pass copies the source `.terrain` to `<island>/Intermediates/PatchedArchetype.terrain`, patches that copy in place — dimensions on `Assets[0].Terrain`, every per-node `"Seed"` field via recursive walk (skipped entirely when `"seed": 0`, leaving the archetype's authored per-node seeds intact for A/B against Gaea's editor preview) — and hands the patched copy to `Gaea.Swarm.exe --Filename`. The on-disk source archetype is never mutated, so there's no file lock and no RAII restore; the patched copy also serves as a debug artifact (open in Gaea). The Sea node `Level` is read (via `ReadArchetypeSeaLevel`, defaulting to `kfGaeaSeaLevelDefault = 0.1f`) but never written, so Gaea's editor preview and the runtime water surface stay in agreement. After the bake, elevation is converted to engine-meters in-process (Gaea's normalized float offset by the read sea level then scaled by Island.json's `elevationMeters` — also written into the archetype as `Terrain.Height` for the bake — yielding `(pixel - fSeaLevelNormalized) * elevationMeters`, NaN/Inf scrubbed to the sea-floor value). The meter-elevation buffer is scanned for the tight bbox of pixels > 1.0 m (`kfCropEpsilonMeters`), the bbox is expanded symmetrically (with edge-clamp overflow pushed onto the opposite side) to a multiple of `4 × kiElevationDivisor` in each axis, and elevation + AO are cropped to that anisotropic rect. Elevation is then box-filter downsampled by `kiElevationDivisor` (4×, defined in `ExportIsland.h`) and `Elevation.r32` is rewritten in place at `cropW/4 × cropH/4`; AO is rewritten at `cropW × cropH`. Color PNG and Normals EXR stay full-res on disk (Gaea writes them; cropping happens in-memory in `ExportIsland` after `Texture` loads them, so the final BC outputs and JPG sidecars land at crop dims). Color is loaded as sRGB-encoded bytes (no gamma re-application before BC7); Normals are loaded linear (gamma-encoding direction vectors is incorrect). Sampled by a vertex grid in `Terrain.vert`, elevation doesn't need color-level resolution; this is the primary disk-size lever for islands. On-disk pixel 0 = sea level / beach, negative = underwater down to `-fBeachOffsetMeters` (i.e., `-fSeaLevelNormalized * elevationMeters`), positive = land up to `elevationMeters - fBeachOffsetMeters`. The bake writes `Intermediates/BakedDimensions.json` before stamping the bake-version sentinel; it carries the anisotropic post-crop world dimensions and the source crop rect. The Islands `ExportJob` ingests the single `Intermediates/` folder: color becomes a standalone BC7 texture chunk, normals BC5, AO BC4, and a per-island material-mask BC7 RGBA (R=rock, G=sand, B=snow, A=flow) packed from four grayscale-PNG sidecars (`Rock.png` / `Sand.png` / `Snow.png` / `Flow.png`) Gaea exports alongside color/normals/AO — each with a full mip chain (`Texture::MakeMipmaps`, which stops once a dimension drops below the BC 4-divisibility floor). The mask texture is cropped to the same anisotropic rect as color/normals, then 4×-downsampled (`Texture::Downsize(2)`) before BC7 encoding, so its mip 0 lands at `cropW/4 × cropH/4` — ~25% of color's footprint. Before each texture's mip chain is built, mip-0 texels whose corresponding downsampled-heightmap sample is below a fixed depth threshold are overwritten with a per-format flat value (color RGB=0 with alpha pinned to 255 so BC7's no-alpha mode stays valid; normals to a tangent-space (0,0,1) sentinel; AO and masks to 0). Camera-visible shallow water (the band from the threshold up to sea level) is preserved so beach transitions stay artifact-free. The mask runs before `MakeMipmaps` so the flat region propagates through the box / linear downsample for free, giving RDO + zlib long constant runs at every mip. The heightmap buffer is read once at the top of the export and reused both for the masks and the chunk payload. Elevation is packed directly into the kIsland chunk payload (as pre-scaled `R32_SFLOAT` meters alongside the mesh) — there is no standalone elevation texture chunk emitted, and the runtime uploads the heightmap to a template-owned image without a second disk read. The per-island mesh in `MeshProcessed.bin` is float3 XYZ on disk; `ExportIsland` strips Z when emitting the kIsland chunk payload (float2 XY pairs), since `Terrain.vert` re-derives Z from the elevation sampler at draw time. The CPU heightmap is the same float-meters data. World dimensions come from `ReadBakedDimensions()` (reads `BakedDimensions.json`'s `widthMeters` / `heightMeters` — anisotropic — and the crop rect for cropping EXRs in-memory) and are stamped into `IslandHeader` as `fWorldFootprintXMeters` / `fWorldFootprintYMeters` + `iHeightmapWidth` / `iHeightmapHeight`. `Handles()` gates on `Intermediates/AmbientOcclusion.r16` existing, so a folder containing only `Island.json` is a no-op until the bake produces one.
- **Scene**: a `.PreExport` marker carries its own version; stale marker forces re-running `PreExport` even when the main chunk is clean. Emits `.MODEL` geometry and per-texture block-compressed intermediates routed three ways by material usage: BC4 for occlusion, BC5 for normals, BC7 otherwise. Primitives from different mesh nodes sharing one glTF material split into distinct material entries while preserving the source index for texture lookup.
- **IBL cubemaps**: do their own timestamp-vs-source dirty checks. Pre-filtered radiance data is written **face-major / mip-minor** to match `TextureUploadManager`'s iteration order.

## Texture Routing

`ExportTexture` routes on filename tags (`[C]`, `[BC4]`, `[BC5]`, `[BC7]`) and explicit format extensions (passthrough, no mip generation). Font-atlas detection strips `[...]` prefixes and cross-references `Fonts/**/*.fnt`; matches use a box-filter mipmap chain.

## Texture Chunk Format

Texture intermediates start with an 8-byte magic sentinel (`kiTextureIntermediateMagic = 0x00000000_BC7E_DA7A`, "BC7E DATA") followed by 3× `int64_t` width/height/mipcount and a zlib stream of all mips concatenated. The magic distinguishes "produced by the current `Texture::Save`" from legacy (pre-magic and/or pre-zlib) files; the `ExportTexture` raw-passthrough reader tolerates both shapes. `MigrateLegacyIntermediates()` in `Main.cpp` upgrades legacy files in place at startup — for BCn it decodes mip 0 and re-encodes with current RDO knobs (one generation of BC7-roundtrip quality loss for islands whose source `.exr` is gone), for R16 it just zlib-wraps. BCn block bytes are RDO-tuned with a small lookback window (4 KB, 256 BC7 blocks) so the byte stream is LZ-friendly without making ERT's O(blocks × window) inner loop blow past the L3-cache cliff on 2K² mips; deflate's own 32 KB window catches longer-range matches. `ChunkHeader` carries the compressed-on-disk size and an uncompressed-size sibling; the runtime `FileManager` decompresses payloads at chunk-load (see [Engine/Source/File/CLAUDE.md](../../../Engine/Source/File/CLAUDE.md)). `.R16G16B16A16_SFLOAT` cubemap intermediates from the IBL convolution path stay in the legacy pre-magic shape — that writer is a separate code path.

## Shader Dirty Tracking

`ExportShader::CheckDirty` parses Makefile-style `.d` depfiles from `glslc -MD` and re-exports when any transitively `#include`'d header is newer than the cached chunk.
