# `DataPacker/Source`

Asset preprocessing tool that converts raw assets (textures, models, shaders, audio, fonts) into optimized binary formats for runtime loading.

## Architecture

Main.cpp orchestrates a multi-phase pipeline: a one-shot migration of legacy `.BC[457]_UNORM_BLOCK` / `.R16_UNORM` intermediates to the current magic-prefixed format (idempotent via the `kiTextureIntermediateMagic` byte-0 check; BCn files get a full decode → re-encode with current RDO knobs, R16 a zlib wrap), then pre-export (Scene, a Gaea bake of island intermediates, Islands) generates intermediates, offline IBL cubemap convolution runs next, main export processes the remaining asset types (every type runs even if an earlier one failed; each type's job failures combine into one MessageBox), then header generation and ThirdParty attribution collection. The Gaea bake is a separate step (not an `ExportJob`) that shells out to `Gaea.Swarm.exe` once per route per island (an island declares one or more routes), parses the resulting heightmap / textures / mesh, and splits each into per-chunk leaves. The bake/split orchestration — route table, archetype patching, elevation scaling, auto-crop, mesh subdivision — is documented in the two paragraphs below (the bake TUs live in `ExportJobs/Island/`); the two-stage dirty sentinels, leaf rejection, and the `ExportIsland` chunk consumer are documented in `ExportJobs/CLAUDE.md`.

Files split for eventual Gaea 3 migration (all in `ExportJobs/Island/`): all Gaea-version-specific logic (executable resolution, archetype patching, Sea-level read) is confined to `GaeaArchetype.{h,cpp}`. The version-agnostic bake/split orchestration spans three TUs sharing the private `BakeIslandIntermediatesInternal.h` (bake-context structs, shared constants, the two cross-TU forward declarations): `BakeIslandIntermediates.cpp` (top-level entry point and route-table resolution), `BakeRoute.cpp` (one route's two-stage Gaea bake plus split), and `ProcessBakedRegion.cpp` (per-region crop / downsample / leaf write). `SubdivideBeachBand.{h,cpp}` is a fourth, self-contained TU: adaptive shoreline mesh densification run once on the full route mesh before the per-region split — triangles straddling beach Z subdivide until shoreline XY edges drop to ≤ 1 m, while out-of-band neighbours absorb shared midpoints without creating new ones so the cascade dies one ring outside the band. `GaeaArchetype.h` is deliberately json-free, so `Island.json → archetype path` resolution (which takes a parsed `nlohmann::json`) stays in `BakeIslandIntermediates.cpp`. The on-disk source `.terrain` is never mutated: each route copies it to its own `Intermediates/PatchedArchetype.terrain`, patches the copy (dims, the single Gaea `Route` node `Choice`, per-node `"Seed"` fields, optional Mesher resolution), and hands that to `Gaea.Swarm.exe` — so sibling routes/islands sharing an archetype never collide and a crashed process can't leave a half-patched source.

The elevation pipeline is meters-absolute end-to-end. Gaea emits float-raw normalized elevation; DataPacker reads (never writes) the archetype's Sea node `Level` (`ReadArchetypeSeaLevel`, falling back to `kfGaeaSeaLevelDefault = 0.1f` when absent), scales by `Island.json`'s `elevationMeters`, and offsets by `fBeachOffsetMeters = Level × elevationMeters` so engine-Z 0 is the beach, water is negative down to `-fBeachOffsetMeters` (the sea floor), land positive. Because `Level` is read rather than mutated, Gaea's editor preview and the in-game water surface agree. The engine pins the sea floor to a single global `common::kfSeaBottomMeters` (-10 m); DataPacker asserts each bake's `-fBeachOffsetMeters` matches it within 0.01 m, so all shipping islands run `elevationMeters = 100` at Level 0.1 — changing either side requires moving `kfSeaBottomMeters` in lockstep. Auto-crop trims only the deepest water: a pixel is kept when its elevation exceeds `seaFloor + kfCropEpsilonAboveSeaFloorMeters` (1 m above the sea floor, i.e. a cut line near -9 m), preserving the whole landmass plus a shallow-water coastline halo. The bake throws if `fBeachOffsetMeters <= kfCropEpsilonAboveSeaFloorMeters` (the cut line would reach sea level and strip the halo). The runtime samples elevation directly with no per-island height or water-depth multipliers.

Single-instance guard is a named Win32 mutex; a second instance waits for the first to finish rather than exiting (build events can stack). Outside the debugger, top-level `try/catch` shows a MessageBox; under the debugger it runs unwrapped so exceptions break in. Three diagnostic CLI modes (`--rdo-sweep`, `--rdo-sweep-full`, `--rdo-sweep-validate`, each taking one image/intermediate path) short-circuit the normal run to profile BC7 RDO lambda / lookback / uber knobs and emit a Pareto frontier — used only when retuning the encoder constants in `Texture.cpp`.

FileManager (`gpFileManager`) owns input/output/temp directory resolution and CLI parsing only. CLI accepts zero args (sandbox defaults) or exactly three (engine-data, project-data, output-dir). `mbCleanExport` forces a full re-export but nothing sets it — no CLI flag exists; it is a debugger/code-edit-only toggle. Vulkan SDK path lookup (`VK_SDK_PATH` + `Bin/` required for glslc / glslangValidator / spirv-opt) is local to the shader exporter's TU. ThirdParty license collection is a free function called from `Main.cpp` post-export.

`Texture` (`ExportJobs/Texture/Texture.{h,cpp}`, beside the `MigrateLegacyIntermediates.{h,cpp}` startup-migration pass) loads (EXR / PNG / raw float / raw uint16), mip-generates, and encodes to BC4/5/7 plus uncompressed R8G8B8A8/R16/R32_SFLOAT, keeping internal pixels as RGBA float at 0–255 scale (not 0..1). BC mip chains terminate once width or height drops below 4 or stops being divisible by 4. BC7 RDO knobs (lambda / lookback window / uber level) are tuned constants at the top of `Texture.cpp`; the RDO encoder internally spawns `HardwareCoreCount() - 2` threads (two physical cores left idle for the OS), so callers serialize whole construct→mip→encode chains behind the static `sEncodeMutex` to bound peak memory. No PNG/EXR writer is wired up (load-only for those formats), so `ExportIsland` crops full-res Color/Normals in-memory rather than re-staging them on disk; JPEG sidecars are a debug-visualization path only.

Pch.h sets `kbIsDataPacker = true` (distinct from engine/game PCH); log categories default to `kVerbose`. Tools builds have no allocation tracker (see `Engine/Source/Memory/CLAUDE.md`), so the engine's LOG float-format-spec ban does not apply here — `{:4.2f}`-style specs in `LOG(...)` are fine.

## Design Patterns

- **Template-based processing**: `RunExportJobs<T>()` provides type-safe job management with dirty checking, constrained by the `IsExportJob` concept (requires `kName`, `Handles()`, and `ExportJob` derivation). Before per-job checks it validates the existing `.manifest`'s `common::DataHeader` — an unreadable header, magic mismatch, or `kiVersion` mismatch dirties the whole type, so a lone `kiVersion` bump triggers a full re-export instead of leaving a manifest the engine would reject. Parallelism is one `std::async` task per matched asset — no central thread pool. `T::Handles(entry)` returns `std::optional<ChunkFlags_t>` to accept-and-tag.
- **Atomic writes**: Outputs written to temp directory first, renamed on success. On any job failure, temp files removed and run returns non-zero without touching prior outputs.
- **Content-based updates**: Generated headers only overwritten when content differs, preventing unnecessary recompilation.
- **Deterministic output**: Assets sorted by relative path before processing for consistent chunk ordering.

## Output Structure

Each asset type produces `.manifest` (CRC-to-chunk-location), `.pack` (binary data), `.h` (C++ CRC constants). Also generates `DataTypes.h` (enum/names only), `Data.h` (aggregates CRC headers), and sibling `Attribution/` directory. Split headers let files needing only the enum avoid recompilation when asset CRCs change.

Manifest layout: `common::DataHeader` then aligned array of `common::ChunkLocation`. Attribution: `<output-parent>/Attribution/<LibraryName>/`; license search matches exact lowercase `license` / `license.md` / `license.txt`, falling back to names containing `copying`/`readme` or exactly `manual.md`. `Prebuilts` skipped; a ThirdParty dir with no recognizable license ASSERTs.
