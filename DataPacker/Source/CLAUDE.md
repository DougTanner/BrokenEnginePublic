# `DataPacker/Source`

Asset preprocessing tool that converts raw assets (textures, models, shaders, audio, fonts) into optimized binary formats for runtime loading.

## Architecture

Main.cpp orchestrates a multi-phase pipeline: a one-shot legacy-raw → zlib migration of `.BC[457]_UNORM_BLOCK` / `.R16_UNORM` intermediates (idempotent: skips files whose payload size doesn't match raw-size math), then pre-export (Scene, a Gaea bake of island intermediates, Islands) generates intermediates, offline IBL cubemap convolution runs next, main export processes asset types in parallel, then header generation and ThirdParty attribution collection. The Gaea bake is a separate step (not an `ExportJob`) that shells out to `Gaea.Swarm.exe` exactly once per island at the requested texture resolution — all Gaea-version-specific logic is confined to that one translation unit for easier migration. The Mesher's `Mesh.gltf` is then run through an adaptive beach-band densification pass: triangles straddling the shoreline are recursively midpoint-subdivided until the longest XY edge meets a fixed engine-meters target, and out-of-band one-ring neighbors absorb the new midpoints via minimal T-junction splits that introduce no further midpoints. The elevation pipeline is meters-absolute end-to-end: Gaea emits float-raw normalized elevation, DataPacker scales by Island.json's `elevationMeters` (also patched into the archetype's `Terrain.Height` before the bake) and subtracts the global constant `kfBeachHeightMeters` (5 m) so pixel value 0 means sea level (beach). To make Gaea actually emit the water surface at that absolute altitude, the archetype's Sea node `Level` is patched to `kfBeachHeightMeters / elevationMeters` (e.g., 0.05 for a 100 m island) before the bake and restored after; Sea node `ShoreHeight` is left untouched (it drives Gaea's shoreline visual effects only, separate from the elevation pipeline). Sea floor depth is consequently a fixed -5 m for every island regardless of `elevationMeters`. The meter-elevation buffer is scanned for the bbox of pixels above the crop epsilon (1.0 m), the bbox is expanded symmetrically to a multiple of `4 × kiElevationDivisor` in each axis, and elevation + AO are cropped to that anisotropic rect (Color/Normals EXRs stay full-res on disk and are cropped in-memory at `ExportIsland` time). Elevation is then box-filter downsampled in-process by `kiElevationDivisor` and the heightmap is written as R32_SFLOAT meters; `Intermediates/BakedDimensions.json` records the post-crop world width / height and the source crop rect, written before the bake-version sentinel so a clean sentinel implies the sidecar is valid. (Elevation is sampled by a vertex grid in `Terrain.vert` and doesn't need per-texel resolution; the auto-crop combined with the downsample is the primary disk-size lever for islands.) The runtime samples directly with no per-island height or water-depth multipliers. Bakes share archetype `.terrain` files across islands, so the patch+bake+restore is always wrapped under a process-local mutex and is RAII-rolled-back to byte-and-mtime-identical state on completion (no `git diff`, no sibling-island re-bakes); the patch covers archetype dimensions, every per-node `"Seed"` field (Gaea's `--seed` CLI flag only mixes a global seed into per-node randomness, so per-node fields must be overwritten directly), and the Sea node `Level` (sets the absolute beach altitude). Single-instance guard is a named Win32 mutex. Outside the debugger, top-level `try/catch` shows a MessageBox; under the debugger it runs unwrapped so exceptions break in.

FileManager (`gpFileManager`) owns input/output/temp directory resolution and CLI parsing only. CLI accepts zero args (sandbox defaults) or exactly three (engine-data, project-data, output-dir). Vulkan SDK path lookup (`VK_SDK_PATH` + `Bin/` required for glslc / glslangValidator / spirv-opt) is local to the shader exporter's TU. ThirdParty license collection is a free function called from `Main.cpp` post-export.

Texture utilities keep internal pixels as RGBA float at 0–255 scale (not 0..1). BC4/BC5/BC7 mip chains terminate once width or height drops below 4 or stops being divisible by 4.

Pch.h sets `kbIsDataPacker = true` (distinct from engine/game PCH); log categories default to `kVerbose`.

## Design Patterns

- **Template-based processing**: `RunExportJobs<T>()` provides type-safe job management with dirty checking, constrained by the `IsExportJob` concept (requires `kName`, `Handles()`, and `ExportJob` derivation). Parallelism is one `std::async` task per matched asset — no central thread pool. `T::Handles(entry)` returns `std::optional<ChunkFlags_t>` to accept-and-tag.
- **Atomic writes**: Outputs written to temp directory first, renamed on success. On any job failure, temp files removed and run returns non-zero without touching prior outputs.
- **Content-based updates**: Generated headers only overwritten when content differs, preventing unnecessary recompilation.
- **Deterministic output**: Assets sorted by relative path before processing for consistent chunk ordering.

## Output Structure

Each asset type produces `.manifest` (CRC-to-chunk-location), `.pack` (binary data), `.h` (C++ CRC constants). Also generates `DataTypes.h` (enum/names only), `Data.h` (aggregates CRC headers), and sibling `Attribution/` directory. Split headers let files needing only the enum avoid recompilation when asset CRCs change.

Manifest layout: `common::DataHeader` then aligned array of `common::ChunkLocation`. Attribution: `<output-parent>/Attribution/<LibraryName>/`; license search tries `LICENSE*` then `copying*` / `readme*` / `manual.md`. `Prebuilts` skipped; a ThirdParty dir with no recognizable license ASSERTs.
